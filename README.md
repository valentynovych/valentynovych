### 🧩 About me

I design and build **distributed backends** — the kind where a single user action
crosses five services, a message broker and a dozen tenant schemas, and still has
to be correct, traceable and idempotent.

- 🏗️ Day to day I work on a **microservice CRM platform**: API gateway, identity &
  JWT issuing, core business domain, payments, reporting, notifications and
  centralized schema migrations.
- 🧵 **Multi-tenancy by schema-per-tenant** — tenant context propagation across HTTP,
  async executors and message consumers.
- 💳 **Payment integrations** (Stripe, Nuvei) — tokenization, webhooks, checksum
  verification, retries and idempotent callbacks.
- 📊 **Reporting & analytics** — two-phase native SQL search, PostGIS geo queries,
  CSV/XLSX exports, timezone-aware dashboards.
- 🔭 I care about **observability and boring, obvious code**: metrics, traces, logs,
  and a diff a reviewer can read in one pass.

### 🚀 What I'm good at

| | |
|---|---|
| **Service design** | Splitting a domain into services that can deploy independently — and keeping their wire contracts backward-compatible while they do. |
| **Multi-tenancy** | Per-tenant schemas, tenant context across threads and queues, cache keys that never leak between companies. |
| **Async & reliability** | RabbitMQ with dead-letter queues, retry classification, at-most-once publishing on commit, idempotent webhook handling. |
| **Reporting** | Native SQL over large tables, paging strategies, streaming exports, PostGIS. |
| **Integrations** | Payment gateways, telephony, email, push, Slack apps, Google Business Profile & Reviews — including the unglamorous parts: OAuth flows, signatures, checksums, callback replays. |
| **Documents** | HTML → PDF generation pipelines (invoices, estimates) with templating and custom fonts. |
